# Control Flow and Collections

## Description
This project demonstrates Python control flow and collection data types by processing vehicle event records. The program filters invalid records, counts vehicles by gate, calculates the average Turnaround Time (TAT), and generates a summary report.

## Features
- Filter invalid vehicle records
- Count vehicles by gate
- Calculate average TAT
- Display record summary
- Remove duplicate vehicles using sets
- Demonstrate list comprehensions
- Use enumerate() and zip()

## File
- vehicle_summary.py

## Concepts Used
- if / elif / else
- for loop
- while loop
- list
- tuple
- dictionary
- set
- list comprehension
- enumerate()
- zip()

## How to Run

```bash
python vehicle_summary.py
```
