# Object Oriented Programming and Testing

## Description
This project demonstrates Object Oriented Programming (OOP) concepts using Python dataclasses. It also includes unit testing with pytest to verify object creation and data validation.

## Features
- Create VehicleEvent dataclass
- Create DetectionResult dataclass
- Unit testing with pytest
- Six passing test cases
- Clean and maintainable project structure

## Project Files

- models.py
- main.py
- test_models.py
- requirements.txt

## Concepts Used

- class
- @dataclass
- pytest
- assert
- PEP 8

## How to Run

Run the application:

```bash
python main.py
```

Run the test suite:

```bash
pytest -v
```

## Output

- Creates VehicleEvent and DetectionResult objects.
- Successfully passes all six pytest test cases.

## Learning Outcome

- Learned Object Oriented Programming in Python.
- Created reusable data models using dataclasses.
- Wrote and executed unit tests using pytest.
- Verified code correctness with assertions.
