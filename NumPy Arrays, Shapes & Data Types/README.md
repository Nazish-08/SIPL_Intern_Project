# NumPy Arrays, Shapes and Data Types

## Description
This project demonstrates NumPy arrays, dimensions, shapes, data types, indexing, slicing and reshaping. It also represents an RGB image using a NumPy array.

## Features
- Create 1D, 2D and 3D arrays
- Inspect array shape, dimensions and data type
- Create arrays using arange(), zeros() and ones()
- Reshape arrays
- Perform array indexing and slicing
- Represent an RGB image as an H × W × 3 array
- Access and modify RGB pixel values

## File

- numpy_arrays.py

## Concepts Used

- np.array()
- np.arange()
- np.zeros()
- np.ones()
- shape
- ndim
- dtype
- reshape()
- indexing
- slicing
- RGB image representation

## How to Run

```bash
python numpy_arrays.py
```
