# Python Fundamentals

## Description
This project covers the fundamentals of Python programming, including environment setup, Python execution, variables, basic data types, user input, and output. It also includes a simple Unit Converter application.

## Features
- Python environment setup
- Virtual environment (venv)
- Python REPL practice
- User input and output
- Variables and data types
- Unit Converter application

## File

- unit_converter.py

## Concepts Used

- Variables
- Data Types (`int`, `float`, `str`, `bool`)
- `input()`
- `print()`
- Basic arithmetic operators
- Python REPL
- Virtual Environment (`venv`)

## How to Run

```bash
python unit_converter.py
```

## Sample Output

```text
Enter kilometers: 5
Meters: 5000
```

## Learning Outcome

- Set up a reproducible Python development environment.
- Learned Python execution and basic syntax.
- Practiced variables, data types, input, and output.
- Built a simple Unit Converter application.
